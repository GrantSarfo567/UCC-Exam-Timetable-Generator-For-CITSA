# UCC Exam Timetable Generator

An automated exam timetable generation system for the Computer Science 
and IT departments of the University of Cape Coast (L100 - L400).

Built with React + FastAPI + Supabase.

## Features
- CSV upload for courses, rooms, and time slots
- Automated conflict-free timetable generation (Graph Colouring Algorithm)
- Calendar view with department filtering
- PDF export with UCC branding
- Conflict detection and resolution log

## Tech Stack
- **Frontend:** React, Tailwind CSS
- **Backend:** FastAPI (Python)
- **Database:** Supabase (PostgreSQL)
